# Dania Portfolio

A personal portfolio website built with HTML, CSS, and Bootstrap.

## Overview
This portfolio showcases my work, skills, projects, and contact information in a clean and modern dark-themed design. It includes a hero section, about me section, skills cards, project cards, contact form, and footer.

## Features
- Responsive layout for desktop and mobile devices
- Navigation links for smooth section scrolling
- Skills and project showcase cards
- Contact section with form UI
- Footer with email and social media links

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
